Executive Read

What Phase 3 is doing

Expanding the playable football campaign from three to eight Host City Challenges with final catalog content, stamp assets, runtime guards, and a single explicit maxMapIndex enable gate — without knockout, legends, economy, or cloud save.

Biggest blocker today

Missing profiles 32–36 and boss roster support IDs. Expansion JSON exists as stubs only. Maps 3–7 must not enable until content + assets + QA pass.

Release posture

Phase 2 release-safety invariants carry forward: local portraits (T0), no live APIs, battle math frozen, save v3 only, cloud save off.

Go / No-Go Status

3-city slice

GO — Phase 2 sign-off stands. Playable maps 0–2 with settlement lite.

8-city runtime

NO-GO until P3-040 gate: content, stamps, guards, manual QA, and validation report complete.

Core Assumptions

  • A1 · maxMapIndex gate is singular

    Only task P3-040 may change FEATURES.maxMapIndex from 2 to 7.

  • A2 · Knockout deferred

    Eighth stamp routes to completion/settlement, not startMap(8) knockout flow.

  • A3 · T0 portraits acceptable

    Jersey fallbacks per 018-portrait-asset-strategy.md until T1 art pipeline approved.

  • A4 · One task, one commit

    Never mix content merge, UI, save, QA recording, and runtime enable in one commit.

Tradeoffs

  • Offline expansion JSON before runtime merge

    Phase 2 prepared stubs so Phase 3 can validate schemas early. Cost: duplicate files until P3-019 merge.

  • Slice-complete screen reused for 8 stamps

    Keeps bridge IDs stable. Copy updates in P3-035 instead of new screen type.

  • Incremental profile authoring

    Profiles 32–36 land as separate commits for atomic validation rather than one 50-player dump.
