Registry Rules

Record, then continue

Do not block Phase 1 implementation for non-blocking visual polish. Capture the issue here with enough context to reproduce it later.

Attach evidence when useful

For UI or gameplay tasks, include browser screenshot paths or concise visual observations in the entry. Keep screenshots out of commits unless explicitly needed.

Separate blocker from polish

Anything that prevents the slice from completing belongs in the active task. This file is for Phase 2 cleanup, asset replacement, and experience refinements.
